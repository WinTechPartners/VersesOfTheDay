# Verses of the Day

A separate free directory with six verified provider profiles, reference selections, links to their original pages, and exact-passage links to This Verse Explained. No AI context or image generation occurs in this app.

## Development

Run npm install, then npm run dev. Production: npm run build. The hosting manifest contains this app's unique Site ID. No API secrets, local runtime data, or the original Git history were copied.

Initial selections retain their original dates; they are not presented as today's verified readings. Expanding to twenty sources, authenticated daily imports, email capture/digest delivery, and binding versesoftheday.online remain follow-up work. No daily scheduler or notifications were activated.

Dependencies currently use a local junction to the original checkout for validation. For a portable checkout, replace the junction with a normal npm install.
